This is the part a .pptx cannot do. A deck is a web page, so a slide can hold working controls. Each button writes a theme token, and every slide in the deck follows. Pick a colour and a face, then flip back through what you have already seen.

When tokens are not enough

Tokens are the floor, not the ceiling.

  • Tokens set colours, typefaces, radius and the wash. Most brands stop here.
  • A theme is a full stylesheet. This deck’s serif emphasis is six lines of it.
  • Add your own layouts, and Claude generates and revises them like the stock ones.
  • Scripts hook into the runtime for graphics and behaviour, like the last slide.
  • A voice file tells Claude how the brand writes and what it never uses.

Answer the worry that a token theme means a plain deck. The layers are tokens, theme CSS, custom layouts, custom scripts and the voice file. All of them live in the fork, and no runtime update touches them.

Every file is wholly slaydy's or wholly yours, so an update is a copy and never a merge. A script shows what changed since your last update and skips anything you edited. That is the answer to the question about keeping a brand through upgrades.
